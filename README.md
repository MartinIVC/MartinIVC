## Proyectos destacados

Estos proyectos personales y académicos muestran cómo aplico lo que aprendo.

### [Scrapping Remates](https://github.com/MartinIVC/scrapping-remates)

Herramienta para consultar remates del Boletín Concursal de Chile sin revisar cada documento manualmente. Reúne extracción de datos, lectura de PDF y una interfaz web para explorar la información.

**Trabajo realizado:** integración del proceso de extracción y organización de datos con su consulta desde un dashboard web.

**Tecnologías:** Python, Flask y pypdf.

### [Medisalud](https://github.com/MartinIVC/medisalud/tree/develop)

Aplicación académica de reserva de horas médicas con portales para pacientes y secretaría. Permite consultar disponibilidad, configurar agendas y gestionar citas y profesionales.

**Trabajo realizado:** desarrollo de la aplicación, integrando interfaz, API y persistencia. La versión funcional más actual está en `develop` y continúa en desarrollo.

**Tecnologías:** React, Vite, Tailwind CSS, Node.js, Express, PostgreSQL y Docker Compose.

[Ver capturas y funcionalidades](https://github.com/MartinIVC/medisalud/tree/develop#vista-previa)

### [Steiner Tree Solver](https://github.com/MartinIVC/steiner-tree-solver)

Proyecto de optimización sobre grafos que explora cómo conectar un conjunto de nodos con un costo reducido. Complementa mis proyectos web con trabajo en algoritmos, estructuras de datos y evaluación de soluciones.

**Trabajo realizado:** implementación de heurísticas y metaheurísticas, validación de soluciones y visualización de resultados.

**Tecnologías:** C++17, Python y Make.
